# Third-Party Notices

This sandbox template is built on **Kali Linux Rolling** and runs on **E2B**.
The installed security tools are independent open-source projects, each with its
own license (for example nmap, sqlite/sqlmap, ffuf, nuclei, pwntools, gdb,
rizin, z3, binwalk, volatility3, tshark). Review each tool's license before
redistribution.

- **E2B** (e2b.dev) - cloud sandbox execution under E2B's terms and data-handling policy.
- **Kali Linux** - rolling distribution and package repositories.
